# Flower Shop Landing — HTML/CSS

This small project reproduces the provided landing page image using only HTML and CSS.

Files:

- `index.html` — main markup
- `styles.css` — styling and layout

How to view:

1. Open `index.html` in a browser (double click or use "Open with" → browser).
2. Replace the hero photo by editing `styles.css` and setting `background-image` on `.hero-card::before` or adding an <img> inside the `.hero-card`.

Notes:

- All icons are emoji placeholders. Replace with proper SVGs or images for a pixel-perfect match.
- Colors, spacing, and typography are tuned to closely match the provided image. Adjust font sizes in `styles.css` if you want exact pixel matching.
